# CCAO-F cheat sheet

**60 q · 120 min · $99 · 720/1000 scaled · closed book · no AI**

| Ch | Remember |
|---|---|
| Evaluate | Accuracy / completeness / relevance. Confident ≠ correct. Verify numbers independently. |
| Verify | Check against **canonical source**. "Are you sure?" ≠ verification. |
| HITL | High-stakes · irreversible · regulated · external · affects people |
| Workflow | Automate (low-risk, repeatable) · Augment (judgement) · Human-only (high-stakes). Chain stages. SOP + prompt library. |
| Governance | Classify data → redact PII/PHI. IP review. Injection (direct vs indirect): untrusted content = data. AUP. |
| Prompting | **R**ole **C**ontext **G**oal **C**onstraints **F**ormat · few-shot · XML tags · decompose · iterate |
| Models | Haiku fast/cheap · Sonnet balanced · Opus deep · match to task |
| Artifacts | Substantial standalone reusable output |
| Projects | Instructions = behaviour · Knowledge = reference. Curate. Avoid dilution. |
| Troubleshoot | Diagnose · one change at a time · long chat drifting → new chat + summary |

**Traps:** trusting fluent output · asking Claude to self-verify · uploading raw PII · biggest model by default · dumping all files into a Project · prompt-only security.
