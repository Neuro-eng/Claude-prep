# 6. Product & model selection

> Model names change. **Verify the current lineup** in the official guide/docs. At time of writing (Nov 2026) the family referenced is Haiku 5.5, Sonnet 5.5, Opus 5.5, with Fable 5.1 above it.

## Model tiers (principle)
| Tier | Strength | Use for |
|---|---|---|
| **Haiku** | Fastest, cheapest | High-volume, simple tasks: classification, extraction, quick drafts |
| **Sonnet** | Balanced | Default for most workplace tasks: analysis, writing, coding help |
| **Opus** | Deeper reasoning | Hard, nuanced, multi-step problems |
| **Fable/Mythos tier** | Frontier capability | Most demanding work (check availability) |

Exam principle: **match model to task**: don't default to the biggest.

## Product surfaces
- **Claude.ai** (web/desktop/mobile) for individuals and teams.
- **Projects**: persistent workspace with custom instructions + knowledge files + chats.
- **Team / Enterprise plans**: shared Projects, admin controls, organisational data terms.
- **Artifacts**: standalone outputs (documents, code, web pages, interactive tools) rendered beside the chat; best for substantial, reusable content, not short conversational answers.
- Connectors / tools: let Claude reach external apps; adds permission and injection considerations.
