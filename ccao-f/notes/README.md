# CCAO-F: Claude Certified Associate – Foundations

**Who it's for:** professionals who use Claude at work (chat, Projects, Artifacts, connectors). No coding.
**Format:** 60 questions · 120 min · scaled 720/1000 · closed book.

## How to use these notes
Each chapter has the same shape: *what the exam tests → concepts → worked example → traps → self-check → learn more*.
Study order: 1 → 8. After each chapter, do the matching domain quiz in the Practice tab and the flashcards.

| # | Chapter | One-line goal |
|---|---|---|
| 1 | Output evaluation | Judge quality: accurate, complete, relevant |
| 2 | Verification & oversight | Check against real sources; know when a human must decide |
| 3 | Workflow design | Decide what to automate, augment, or keep human |
| 4 | Governance & risk | Protect data, IP; recognise prompt injection |
| 5 | Prompting | Write prompts that work the first time |
| 6 | Product & model selection | Pick the right model and feature |
| 7 | Configuration & knowledge | Set up Projects and knowledge properly |
| 8 | Troubleshooting | Diagnose and fix poor results |

> Chapter titles follow public descriptions of the blueprint. The official Exam Guide is authoritative. Compare after 17 Nov.
