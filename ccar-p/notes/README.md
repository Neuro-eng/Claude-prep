# CCAR-P: Claude Certified Architect – Professional

**Who it's for:** solution architects/consultants designing and governing Claude-based solutions.
**Format:** 63 questions · 120 min · scaled 720/1000 · scenario-based (multiple choice + multiple response).

## How the exam thinks
It asks: *"Given this client situation, what do you recommend and why?"* Correct answers are usually:
1. The **simplest design** that meets the requirement
2. Backed by **measurement** (evals) rather than opinion
3. Protected by **enforced controls**, not prompt wording
4. Honest about **trade-offs** (cost, latency, accuracy, risk)
5. Agreed with stakeholders **before** building
