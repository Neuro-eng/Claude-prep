# Exam-day checklist

## 1 week before
- [ ] Name on Pearson profile == government ID, exactly
- [ ] OnVUE system test passed on exam machine + network (repeat on the day)
- [ ] Work laptop? Ask IT to allow Pearson sites, or use a personal machine
- [ ] Booking confirmed; know the 48 h reschedule cutoff

## Day before
- [ ] Light revision of cheat sheets only. Sleep.
- [ ] Clear-desk plan: no paper, phone, watch, second monitor

## On the day
- [ ] Check-in opens 30 min early: ID photo, face photo, 360° room scan
- [ ] Quiet closed room, single monitor
- [ ] ~2 min per question; flag and move on if stuck >3 min
- [ ] "Select TWO": pick exactly that many (assume no partial credit)
- [ ] Never leave blanks
- [ ] Do NOT use AI or translation tools (banned)

## Elimination heuristics (CCAR-P especially)
1. Prefer the **simplest design that meets the requirement** (single call < workflow < agent < multi-agent).
2. Compliance/safety needs **enforced controls**, not "add it to the prompt".
3. Wrong answers are often "use the biggest model", "add more context", or "build before agreeing success criteria".
4. Poor answers? Diagnose **retrieval vs. model vs. prompt** before changing anything.
5. High-stakes or irreversible action → human-in-the-loop.
